### 👨‍💻 Protocolos de Ingeniería Senior

Para garantizar la calidad de grado industrial, todos los proyectos siguen estos protocolos:

- **🏗️ Arquitectura**: Diseño Hexagonal, Microservicios y Clean Architecture.
- **🔐 Seguridad**: Implementación de **OWASP Top 10**, JWT, Argon2 y Cifrado Simétrico.
- **🚀 DevOps**: Contenerización con Docker, Orquestación y Pipelines CI/CD.
- **🧪 Calidad**: Cobertura de tests unitarios e integración con Vitest/Jest.
