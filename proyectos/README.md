# Senior Project Portfolio: ALBA-OS Collection

Este repositorio contiene una colección de proyectos full-stack de grado de producción, diseñados bajo una arquitectura limpia y principios de ingeniería senior.

## Proyectos Disponibles

1.  **ALBA-OS Control Center**: Dashboard de monitorización de servicios cloud en tiempo real. (TypeScript, Redis, Framer Motion)
2.  **Neural Link Guard**: Sistema de seguridad perimetral para APIs REST con detección de intrusiones. (Express, Python, Docker)
3.  **Echo Vault Storage**: Almacenamiento cifrado punto a punto para activos digitales de alta sensibilidad. (Go, PostgreSQL, AWS S3)
4.  **Bio-Sync Health Tech**: Aplicación para sincronización de datos biométricos y análisis de rendimiento deportivo. (React Native, Firebase, GraphQL)
5.  **Crypto Terminal Pro**: Dashboard de trading de alta fidelidad con actualizaciones vía WebSockets. (Next.js, Socket.io, Tailwind)

---

## Equipo Senior asignado:
- **Arquitecto**: Diseño Hexagonal y modular.
- **Backend Senior**: Node.js/TypeScript, Clean Architecture.
- **Cybersecurity**: OWASP Top 10, JWT, Argon2.
- **DevOps**: Docker, CI/CD, scripts de ejecución.
